# Reproducibility

Use Python 3.10+ and run `pytest`, `python scripts/run_demo.py`, and `python scripts/run_benchmark.py`. CI repeats the unit suite on Python 3.10, 3.11, and 3.12 and runs deterministic benchmark scripts on Python 3.12.

For publications record the commit SHA, Python version, benchmark case list, orchestration mode, evidence limit, candidate limit, generated-test policy, and any model/provider configuration.
