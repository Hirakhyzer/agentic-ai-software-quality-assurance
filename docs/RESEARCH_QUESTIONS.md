# Research Questions

1. Does runtime evidence improve end-to-end repair correctness over static-only QA agents?
2. Which runtime evidence is useful: exceptions, coverage, traces, state snapshots, or logs?
3. How should evidence be compressed so agents receive causal signal rather than trace noise?
4. Can agent specialization improve issue reproduction, test generation, localization, repair, and verification?
5. How often do plausible patches overfit visible tests?
6. When should an agent abstain and request developer review?
7. How do cost, latency, evidence size, and tool calls trade off against repair correctness?
