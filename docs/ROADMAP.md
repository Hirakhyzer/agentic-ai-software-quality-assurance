# Research Roadmap

## v0.2
- subprocess/container execution isolation;
- statement/branch coverage and spectrum-based fault localization;
- mutation testing and test adequacy metrics;
- multi-file benchmark cases;
- patch-diff minimization and regression selection;
- uncertainty/confidence and abstention calibration.

## v0.3
- pluggable LLM-backed specialized agents;
- evidence-budget ablations;
- agent debate/cross-checking;
- repository-scale tasks and external benchmark adapters.

## dissertation-scale
Evaluate when runtime evidence improves or harms agentic QA, how evidence should be selected, and how developer control/abstention can prevent plausible-but-wrong automated repairs.
