# References and Research Context

Selected context for the research direction:

1. Haque, M. et al. **Towards Effectively Leveraging Execution Traces for Program Repair with Code LLMs.** KnowledgeNLP at ACL 2025. https://aclanthology.org/2025.knowledgenlp-1.17/
2. Zhang, L. et al. **Can AI Fix Buggy Code? Exploring the Use of Large Language Models in Automated Program Repair.** IEEE Computer / NIST, 2025. https://csrc.nist.gov/pubs/journal/2025/06/can-ai-fix-buggy-code/final
3. Wu, J. et al. **Runtime Execution Traces Guided Automated Program Repair with Multi-Agent Debate.** arXiv:2604.02647, 2026. https://arxiv.org/abs/2604.02647
4. Huang, Z., Xu, L., Zhang, H. **Multi-Perspective Agentic Program Repair via Code Property Graphs and Temporal Execution Graphs.** arXiv:2607.12605, 2026. https://arxiv.org/abs/2607.12605

The framework does not claim to reproduce results from these works. They motivate runtime evidence, evidence selection, multi-agent reasoning, program repair, and human-controlled assurance.
